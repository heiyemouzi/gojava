# 01 架构说明

## 总览

```
                ┌─────────────────────────────┐
   客户端 ─────► │  Nginx (静态资源/HTTPS 终结)  │
                └──────────────┬──────────────┘
                              ▼
                ┌─────────────────────────────┐
                │  Go API 网关 (Gin) :8080    │
                │  JWT 校验 / 限流 / 熔断     │
                │  租户识别 / 黑白名单         │
                │  WebSocket 长连接           │
                └──┬──────────────┬───────────┘
                   │ gRPC/HTTP    │
        ┌──────────▼──┐    ┌─────▼────────────┐
        │ Go 中台服务  │    │ Java 业务域       │
        │ 文件/告警/   │    │ auth-center :8081│
        │ 日志调度     │    │ tenant/erp/mes... │
        └──────┬───────┘    └──────┬──────────┘
               ▼                  ▼
        ┌──────────────────────────────────────┐
        │ MySQL / Redis / ES / TDengine / MinIO │
        │ RocketMQ (事件解耦)                  │
        └──────────────────────────────────────┘
```

## 服务清单

| 服务 | 语言 | 端口 | 说明 |
|---|---|---|---|
| gateway | Go | 8080 | 唯一对外入口，所有请求先过这里 |
| auth-center | Java | 8081 | 登录、发 JWT、刷新、登出、密码校验 |
| tenant-service | Java | 8082 | 租户/用户/角色管理示例 |
| erp-service | Java | 8083 | 订单/库存/采购/财务（预留） |
| mes-service | Java | 8084 | 工单/报工/质检 + Flowable（预留） |

## 通信约定

- **外部 → 网关**：HTTP/HTTPS，RESTful，`/api/**`。
- **网关 → 后端**：HTTP 内网调用（本地开发），生产建议切 gRPC。
- **网关校验 JWT 后，必须把用户身份透传给后端**（见 03-auth-design）：
  - `X-User-Id`、`X-Tenant-Id`、`X-Username`、`X-Roles`
  - 后端**必须信任这些头来自网关**，内网防火墙禁止外部直接访问后端端口。
- **异步事件**：业务写库后发 RocketMQ，Go 中台消费做告警/同步/推送。

## 配置中心

- Go 网关：本地 `etc/gateway.yaml` 起步，生产切 **etcd**。
- Java 服务：**Nacos**（Spring Cloud Alibaba）。
