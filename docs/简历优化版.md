### gojava 微服务 SaaS 框架（个人项目）　2026.10-至今
**技术栈**：Go + Gin / Spring Boot 3 / MyBatis-Plus / MySQL / Redis / Vue3 + Vite

**项目描述**：按真实生产架构设计的 Go+Java 混合微服务 SaaS 系统，包含统一网关、鉴权中心、商品库存、订单、租户用户管理五个模块。

**核心工作**：
1. **统一网关（Go/Gin）**：实现 JWT 校验中间件、IP 限流、CORS、反向代理；校验通过后将用户身份（X-User-Id/X-Tenant-Id）透传后端，后端零鉴权代码
2. **鉴权中心（Spring Boot）**：实现登录、BCrypt(cost=12) 密码校验、JWT 双 token（access 2h + refresh 7d）签发；用户/角色/租户 RBAC 管理
3. **订单全链路**：下单 → Feign 调用商品服务读库存/价格 → 条件 UPDATE 扣库存（防超卖）→ 本地事务写订单主表+明细；订单列表、取消
4. **多租户隔离**：所有业务表带 tenant_id，JWT claims 携带租户信息，按租户隔离数据
5. **服务间调用**：OpenFeign 声明式客户端，支持后续切 Nacos 服务发现
6. **前端**：Vue3 + Vite + Element Plus + Pinia，登录/下单/订单列表/商品库存/租户用户管理
